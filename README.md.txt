How to start up Project:


requirements:
-Need two pc's that are connected to the same network.
-Need to have admin rights to allow access to bypass any firewalls.

Start up instructions:
-Have two pc's one each running the .exe
-One pc selects Host, the other selects client
-(WARNING!!!)The Host pc will then display the pc's IP address 
-The Client pc will have an input text box. Insert the hosts IP address to connect.
-Once connected the Host will have the option of which mode to select "Participant testing", "Random Map" or "seed selection"
-Selecting any one of these will take both players into a map and a best of three 1v1 will start.
-Once the Best of three is concluded they will get asked if they want to rematch, Play next map (Only works in the Participant testing Mode), Or back to Main menu


Controls:
Movement: WASD
Aim: Mouse
Shoot: Left Mouse button
Crouch: Left control
Sprint: Left Shift
Jump: Space Bar

Modes:
"Participant Testing":
A random order of 5 maps where 3 of which are preselected procedurally generated maps the other 2 are manually designed maps. The participant will play on all 5 maps and part of the survey is to guess which is procedurally generated and which is manually designed?

"Random Map":
As implied A random seed is selected and they generated.

"Seed Selection":
This is a text box where the Host enters a seed number and a corrisponding map will be generated from this
